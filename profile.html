Image Gallery with Filters and Lightbox

Project

This project helps users organize, browse and view images by catagory. Users can filter images using different categories and open them in a lightbox for a better view - all without leaving the page.

Challenges Faced

  • Implementing category filters to show the right images.
  • Creating a lightbox effect without leaving the page.
  • Managing user data and image uploads.
  • Handling image preview and file input issues.

How I Solved It

  • Used JavaScript to filter images based on the category selection.
  • Implemented a lightbox to view images clearly with next/previous controls.
  • Used localStorage to save user data and gallery preferences.
  • Handled file input and image preview using File API.
